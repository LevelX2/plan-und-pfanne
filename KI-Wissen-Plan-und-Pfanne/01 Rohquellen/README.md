# Rohquellen

Dieser Bereich sammelt projektnahe Originalquellen oder belastbare Referenzen auf solche Quellen.

## Ablageprinzip
- `repo-root/` für relevante Dateien aus dem Repository oder deren Rohquellen-Referenzen
- `externe-quellen/` für externe Web- oder Dokumentquellen
- weitere Unterordner nur bei klarer fachlicher Trennung

## Regeln
- Rohquellen werden nicht inhaltlich umformuliert.
- Bei Referenzseiten werden Quelle, Pfad oder URL und Abrufdatum klar genannt.
- Die eigentliche Wissensverdichtung passiert erst in `02 Wissen`.
